# Architecture Review - Project A

**Date:** 14 March  
**Attendees:** Engineering Manager, Security Lead, Product Owner, two backend engineers

## Decisions
- Keep **HS256** for the first release. Asymmetric signing (RS256) is deferred because the key-management work would delay launch.
- Access tokens stay at **15 minutes**. Security asked for 10; the team agreed 15 is acceptable if refresh tokens rotate on every use.
- Statement PDFs will be generated by a queue worker, not inside the API request.
